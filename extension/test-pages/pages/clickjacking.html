Clickjacking Defenses

Simulates a page that tries to hide the kura dropdown and trick the user into clicking a candidate.

Expected Behavior
  • Host opacity attack: after clicking the button, focus Username → the dropdown is torn down as soon as the page rewrites the host's style (it does not stay invisible and clickable)
  • Page filter attack: html { filter: opacity(0.01) } → clicking a candidate does nothing
  • Overlay attack: a pointer-events: none decoy with max z-index → the dropdown is still drawn above the decoy (top layer); in Chrome, a click while occluded is also ignored
  • Clicking a candidate within 300ms of the dropdown appearing is ignored
  • "Reset" restores normal behavior: selecting a candidate fills the form

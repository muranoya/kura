WebAuthn / Passkey (kura extension interception test)

Calls navigator.credentials.create() / .get() directly. This is not a real relying party server — there's no backend to verify the attestation/assertion. Use this page to confirm kura intercepts the calls, opens the ritual window, and returns a well-formed credential object; check the DevTools console for the raw result.

Prerequisites
  • 拡張機能の設定で「パスキー対応（ベータ）」がONになっていること
  • Vaultがアンロックされていること
  • 「Create Passkey」実行時、儀式ウィンドウで紐付け先のloginエントリ（または新規作成）を選ぶ
  • 「Get Passkey」は、直前に作成したPasskeyに対応するloginエントリがある状態で実行する
